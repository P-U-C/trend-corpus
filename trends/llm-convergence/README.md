# LLM Convergence

This theme documents a method for treating cross-model ticker convergence as an attention signal. The hypothesis is that consumer LLMs trained on similar internet data may route retail users toward the same small set of tickers when a sector narrative becomes salient.

The public corpus stores the method, sources, claims, thesis, decision packet, and watchlist. The private scanner consumes a generated `convergence-latest.json` file through a schema boundary, keeping the populator and trading runtime segregated.
